## ➕ Submit Your Project

Are you a Kuwaiti developer with an open-source project? Submit it to be featured!

**[Open a GitHub Issue →](https://github.com/SiteQ8/KW-OS/issues/new?title=[NEW+PROJECT]&body=Project+Name:%0AGitHub+URL:%0ADescription:%0ACategory:)**

Requirements:
- Open-source (any license)
- Built by a developer based in Kuwait (or Kuwait-related)
- Active repository on GitHub

## ✨ Directory Features

- 🔍 **Real-time search** across project names, descriptions, authors, and tags
- 🏷️ **Category filter** with scrollable pills + dropdown
- 📊 **Sort** by Featured, Name A-Z, or Newest
- 🌙 **Dark mode** with localStorage persistence
- 📱 **Responsive** — desktop, tablet, mobile
- ➕ **Submit project** via GitHub Issues
- ⚡ **Zero dependencies** — pure HTML/CSS/JS
